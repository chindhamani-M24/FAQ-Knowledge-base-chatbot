# 🤖 Interactive FAQ & Knowledge Base Chatbot

A simple Python project that answers user questions using Natural Language Processing (NLP) and similarity matching (`scikit-learn`).

---

## 🚀 Features
* **Semantic Question Matching:** Matches what you type against a predefined FAQ database.
* **Instant Answers:** Uses TF-IDF and Cosine Similarity to find the best response in real-time.
* **Interactive Terminal Loop:** Test out questions live.

---

## 💻 How to Run in Google Colab

1. Open [Google Colab](https://colab.research.google.com/).
2. Create a new notebook.
3. Paste and run your Python script (or copy the script into your code cells) to start chatting with the bot!

---

## 🛠️ Tech Stack
* Python 3.x
* Pandas
* Scikit-Learn
